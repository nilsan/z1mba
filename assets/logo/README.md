# z1mba logo

The skyline of the Zimba (2643 m, Rätikon, Vorarlberg) as seen from the Saulakopf,
traced by hand from
[Zimba vom Saulakopf 1.JPG](https://commons.wikimedia.org/wiki/File:Zimba_vom_Saulakopf_1.JPG)
by Friedrich Böhringer, licensed
[CC BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/).

Because they are drawn from that photo, the logo files in this folder and the trace in
`tools/make_logo.py` are shared under the same terms:
[CC BY-SA 2.5](https://creativecommons.org/licenses/by-sa/2.5/), credit "z1mba logo, after a
photo by Friedrich Böhringer". The rest of the repository is under the Mozilla Public
License 2.0.

| File | Use |
|---|---|
| `z1mba-mark.svg` | the filled silhouette |
| `z1mba-outline.svg` | the skyline as a line: the path for milling the logo with a V-bit |
| `z1mba-icon.svg` | square tile for a favicon or the Home Assistant device |

Regenerate with `python3 tools/make_logo.py`. `--view schruns` draws an alternative from a
public-domain photo taken from Schruns.
